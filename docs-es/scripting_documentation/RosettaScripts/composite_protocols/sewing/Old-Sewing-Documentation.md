#Documentación del SEWING antiguo
Como indica el título, estos pasos están obsoletos, pero se conservan como referencia

##Los cuatro pasos del SEWING antiguo

1. [[Generación de modelos|model-generation]] - Extracción de «modelos» a partir de estructuras nativas
2. [[Comparación de modelos|model-comparison-with-geometric-hashing]] - Comparación estructural de los modelos entre sí mediante un algoritmo de hash geométrico
3. [[Ensamblaje|assembly-of-models]] - Unión de modelos según su superposición estructural para formar esqueletos novedosos
4. [[Refinamiento|Refinement of SEWING assemblies]] - Refinamiento de los esqueletos, diseño de cadenas laterales y selección de las estructuras generadas con SEWING
