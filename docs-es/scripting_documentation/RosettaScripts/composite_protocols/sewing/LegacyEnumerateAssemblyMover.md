#LegacyEnumerateAssemblyMover
##Nota: esta página es de LegacySEWING.
**Esta página está obsoleta. Para obtener información sobre la versión actual de SEWING, visita las páginas [[AssemblyMover]] y [[AppendAssemblyMover]].**
El EnumerateAssemblyMover es un mover del marco de [[SEWING]]. Este mover recorre exhaustivamente todos los caminos posibles del SewGraph para crear ensamblajes. Por tanto, es útil cuando no hay suficientes nodos (subestructuras). Actualmente admite subestructuras basadas en cinco estructuras secundarias.

Este mover no está disponible por ahora en la versión publicada de Rosetta.
