## AntibodyDesignModeler

###Autor
Jared Adolf-Bryfogle; jadolfbr@gmail.com; 
PI: Roland Dunbrack

Forma parte del marco de trabajo RosettaAntibody y RosettaAntibodyDesign (RAbD)

###Propósito

Ejecuta protocolos típicos de Rosetta, como minimización, docking, FastRelax, backrub y empaquetado (todos con o sin diseño), construyendo este mover.  Por ahora la API no está conectada a RosettaScripts, pero está previsto hacerlo.  De momento usa PyRosetta para acceder a él, o escríbeme un correo para más información.
