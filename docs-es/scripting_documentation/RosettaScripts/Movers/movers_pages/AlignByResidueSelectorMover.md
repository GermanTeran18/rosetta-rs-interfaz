#AlignByResidueSelectorMover
[[include:mover_AlignByResidueSelectorMover_type]]

El mover requiere que ambas selecciones tengan el mismo número de residuos seleccionados.  
La Pose de referencia debe cargarse o guardarse con [[SavePoseMover]].

Usando **ChainResidueSelector**s, esto sería equivalente a [[AlignChainMover]].
