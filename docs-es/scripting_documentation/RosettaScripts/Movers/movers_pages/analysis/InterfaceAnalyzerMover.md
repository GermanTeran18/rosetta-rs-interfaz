## InterfaceAnalyzerMover

Este [[mover]] lo sirve directamente la aplicación [[InterfaceAnalyzer|interface-analyzer]].  Consulta esa página para ver las referencias. 

Calcula energías de unión, áreas de superficie de interfaz enterradas, estadísticas de empaquetado y otras métricas de interfaz útiles para evaluar interfaces de proteínas.
