#Referencia de la clase utility::vector1

Descripción detallada
---------------------

vector1 es un [[vectorL]] con el índice inferior fijado en 1.

 Nota   
-   std::vector con índices que empiezan en 1 y algunos extras
-   Se puede construir y asignar a partir de std::vector, e intercambiar con std::vector
-   Se puede comparar con std::vector: compara el contenido ignorando los índices
-   Se puede convertir explícitamente a std::vector
-   Aquí es seguro heredar públicamente de la plantilla concreta [[vectorL]]
