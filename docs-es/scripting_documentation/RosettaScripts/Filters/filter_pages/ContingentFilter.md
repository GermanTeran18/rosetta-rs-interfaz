# ContingentFilter
*Volver a la página de [[Filtros|Filters-RosettaScripts]].*
## ContingentFilter

Un filtro especial que permite que los movers fijen su valor (pasa/falla). Después, este valor se puede usar en el protocolo junto con [[IfMover]] para controlar el flujo de ejecución según el éxito del mover.

```xml
<ContingentFilter name="(&string)"/>
```
