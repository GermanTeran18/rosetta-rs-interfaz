##Metadatos

`Mover` creado por Labonte <JWLabonte@jhu.edu>.

##Descripción
Un [[EnzymaticMover]] para simular la fosforilación de un `Pose`.

Este `Mover` simula la actividad de una enzima quinasa virtual sobre un `Pose`, fosforilando un residuo en una posición de secuón biológicamente relevante.
