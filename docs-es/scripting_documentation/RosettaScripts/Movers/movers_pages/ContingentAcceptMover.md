# ContingentAcceptMover
*Volver a la página de [[Movers|Movers-RosettaScripts]].*
## ContingentAcceptMover

Calcula el valor de un filtro antes y después del movimiento, y devuelve false si la diferencia entre los valores del filtro es mayor que delta.

```xml
<ContingentAccept name="( &string)" mover="(&string)" filter="(&string)" delta="(&Real)"/>
```
