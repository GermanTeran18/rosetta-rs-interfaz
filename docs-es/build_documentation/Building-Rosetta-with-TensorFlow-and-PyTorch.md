Como Rosetta solo usa libtorch y no el envoltorio de Python, hemos cambiado a usar simplemente `extras=torch`, y la página de documentación pertinente es [[Building Rosetta with TensorFlow and Torch]].

En versiones anteriores de Rosetta (p. ej., Rosetta 3.14) puede que aún tengas que usar `extras=pytorch`. Aparte de esa sustitución, el enlace de documentación anterior debería seguir siendo válido.
