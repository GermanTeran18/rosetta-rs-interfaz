#Biblioteca utility

La biblioteca `       utility      ` contiene funciones y clases que abstraen conceptos independientes del proyecto Rosetta en general. Entre ellos están componentes básicos como la entrada y salida simple, los sistemas de archivos, los algoritmos y contenedores, la portabilidad y similares.

Como la mayoría de las bibliotecas llamadas "utility", esta es una especie de cajón de sastre.
