##Metadatos

`Mover` creado por Labonte <JWLabonte@jhu.edu>.

##Descripción
Un `[[EnzymaticMover]]` para simular la metilación de un `Pose` que contiene ADN.

Este `Mover` simula la actividad de una enzima ADN metiltransferasa virtual sobre un `Pose`, metilando un residuo en una posición de secuón biológicamente relevante.
