#Tutorial de Features: conceptos básicos de GGplots2

Se recomienda el paquete de R [ggplot2](http://had.co.nz/ggplot2/) para hacer gráficos. Sigue la [Grammar of Graphics](http://www.springer.com/statistics/computanional+statistics/book/978-0-387-24544-7) y fomenta pensar en los gráficos como algo separado de los datos que representan. Fundamentalmente, un gráfico consta de [*capas*](http://had.co.nz/ggplot2/layer.html), cada una de las cuales consta de [elementos estéticos](http://had.co.nz/ggplot2/geom_.html) visuales y de un *mapeo* de los datos a esos elementos estéticos. Al definir la semántica del gráfico con independencia de los datos, se puede generar el mismo gráfico para datos distintos.
