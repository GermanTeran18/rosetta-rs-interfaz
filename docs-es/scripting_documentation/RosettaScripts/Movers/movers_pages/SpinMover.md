# SpinMover
*Volver a la página de [[Mover|Movers-RosettaScripts]].*
## SpinMover

Permite un giro aleatorio alrededor de un eje definido por el jump. Funciona especialmente bien combinado con un loopOver o, mejor, con un GenericMonteCarlo y otros movers. Usa SetAtomTree para definir los átomos del jump.

```xml
<SpinMover name="(&string)" jump_num="(1 &integer)"/>
```
