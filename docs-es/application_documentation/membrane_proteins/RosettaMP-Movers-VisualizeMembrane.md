# Movers de visualización: Visualize Membrane Mover

## Descripción

Este Mover se puede usar cuando la visualización se hace fuera de Pymol. Si usas Pymol, te recomendamos la visualización integrada del PymolMover (AÑADIR ENLACE AQUÍ). Escribe heteroátomos (HETATM) en el archivo PDB.

## Interfaz de RosettaScripts

Las siguientes opciones están disponibles mediante RosettaScripts:
`spacing` - Float - Separación deseada de los HETATM de la salida PDB que representan la bicapa de membrana.
`width` - Float - Mitad del ancho del cuadrado de membrana visualizado en el plano xy. El valor predeterminado es 100A.
`thickness` - Float - Mitad (¿correcto?) del grosor de la membrana.
