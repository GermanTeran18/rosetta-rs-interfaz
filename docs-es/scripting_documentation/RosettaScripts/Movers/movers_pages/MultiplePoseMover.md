# MultiplePoseMover
*Volver a la página de [[Mover|Movers-RosettaScripts]].*
## MultiplePoseMover

Este mover permite implementar en un solo script un protocolo de «distribuir y recoger» de varios pasos, por ejemplo ab initio seguido de agrupamiento por RMSD, o docking seguido de diseño.

Consulta la página [[MultiplePoseMover|RosettaScripts-MultiplePoseMover]] para más detalles y ejemplos.
