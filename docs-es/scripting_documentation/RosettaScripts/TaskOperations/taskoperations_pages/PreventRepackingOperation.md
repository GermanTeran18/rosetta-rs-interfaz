# PreventRepacking
*Volver a la página de [[TaskOperations|TaskOperations-RosettaScripts]].*
## PreventRepacking

No permite ningún reempaquetado del residuo especificado. Congela residuos.

    <PreventRepacking name="(&string)" resnum="(0 &int)" />

<br/>
*Para especificar varios residuos, consulta el [[ResidueSelector|ResidueSelectors]] más flexible [[Index|ResidueSelectors#residueselectors_conformation-independent-residue-selectors_residueindexselector]], así como [[OperateOnResidueSubset|OperateOnResidueSubsetOperation]] y [[PreventRepackingRLT|Residue Level TaskOperations]].*
