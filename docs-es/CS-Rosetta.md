# CS-Rosetta

Chemical-Shift-Rosetta (CS-Rosetta) es una herramienta para predecir la estructura de proteínas a partir de datos de desplazamiento químico de RMN.
En particular, puede tomar como entrada los desplazamientos químicos de RMN de <sup13</sup>CA, <sup>13</sup>CB, <sup>13</sup>C', <sup>15</sup>N, <sup>1</sup>HA y <sup>1</sup>HN, y usar estos datos para seleccionar [[fragmentos|fragment-file]] de PDB (con desplazamientos similares) para la predicción de estructura con Rosetta.
Hay más información sobre CS-Rosetta en sitios externos: [[http://spin.niddk.nih.gov/bax/software/CSROSETTA/]] y [[http://csrosetta.chemistry.ucsc.edu/]].
