# RestrictResiduesToRepacking
*Volver a la página de [[TaskOperations|TaskOperations-RosettaScripts]].*
## RestrictResiduesToRepacking

Restringe una cadena de residuos delimitados por comas al reempaquetado. Sin diseño.

     <RestrictResiduesToRepacking name="(&string)" residues="(0 &integer ',' separated)"/>

<br/>
*Para un sistema más flexible, consulta el [[ResidueSelector|ResidueSelectors]] [[Index|ResidueSelectors#residueselectors_conformation-independent-residue-selectors_residueindexselector]], así como [[OperateOnResidueSubset|OperateOnResidueSubsetOperation]] y [[RestrictToRepackingRLT|Residue Level TaskOperations]].*
