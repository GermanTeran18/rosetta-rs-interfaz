# Opciones sugeridas

Rosetta mejora constantemente.
Por desgracia, las mejoras suelen ser opcionales (opt-in) aunque sean útiles universalmente (o casi).

Estas son algunas opciones que serían las predeterminadas si no nos importara mantener el comportamiento antiguo:

* `-parser:never_rerun_filters true` evita que rosetta_scripts llame varias veces al mismo filtro. Según algunos, esta opción activa el comportamiento esperado y el comportamiento heredado resulta sorprendente para los recién llegados.
