_Documentación de sintaxis de etiquetas generada automáticamente:_

---
Se usa para especificar un nombre de alias en la StructureDefinition para un residuo especificado

```xml
<SetResidueAlias name="(&string;)" alias_name="(&string;)"
        segment_name="(&string;)" residue="(&non_negative_integer;)" />
```

-   **alias_name**: (OBLIGATORIO) Nombre del alias que se asigna al residuo indicado
-   **segment_name**: Argumento opcional para especificar en qué segmento está este residuo. Si se indica, la numeración de residuos es local dentro del segmento.
-   **residue**: (OBLIGATORIO) Número del residuo para el que se especifica un alias
