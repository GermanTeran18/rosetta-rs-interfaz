# SpecificResiduesNearInterface
*Volver a la página de [[Filtros|Filters-RosettaScripts]].*
## SpecificResiduesNearInterface

Filtra los Poses que tienen un conjunto específico de residuos cerca de la interfaz. Por ejemplo, puede ser útil para diseños que dependen de que, digamos, el extremo N esté cerca de la interfaz.

```xml
<SpecificResiduesNearInterface name="(&string)" task_operation="(&string)"/>
```
