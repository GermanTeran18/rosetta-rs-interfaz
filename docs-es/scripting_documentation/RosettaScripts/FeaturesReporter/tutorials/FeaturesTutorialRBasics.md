#Tutorial de Features: conceptos básicos de R

1. Instala el IDE RStudio: [RStudio](http://www.rstudio.com)

2. Lee este libro de principio a fin: [The Art of R Programming, de Norman Matloff](http://heather.cs.ucdavis.edu/~matloff/132/NSPpart.pdf)

3. Configura el directorio de features como un proyecto en RStudio y mira otro código como ejemplo. Matt O'Meara ha dejado muchos README por todo el proyecto, ¡así que asegúrate de leerlos!
