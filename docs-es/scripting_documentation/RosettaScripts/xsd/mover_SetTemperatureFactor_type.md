_Documentación de sintaxis de etiquetas generada automáticamente:_

---
Aprovecha el campo del PDB de los factores de temperatura para guardar en su lugar valores de filtros

```xml
<SetTemperatureFactor name="(&string;)" filter="(&string;)"
        scaling="(1.0 &real;)" />
```

-   **filter**: Filtro que se aplica
-   **scaling**: Escala el valor del filtro por esta cantidad antes de guardarlo en el factor de temperatura
