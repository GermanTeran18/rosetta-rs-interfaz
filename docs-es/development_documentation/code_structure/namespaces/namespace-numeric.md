#Biblioteca numeric

La biblioteca `       numeric      ` abstrae conceptos matemáticos que son independientes del proyecto Rosetta en general. Entre ellos están los vectores de coordenadas, las matrices de coordenadas, las funciones numéricas, geométricas y trigonométricas, las constantes para conversiones y similares.
