# ConvertVirtualToRealMover
*Volver a la página de [[Movers|Movers-RosettaScripts]].*
## ConvertVirtualToRealMover

[[include:mover_ConvertVirtualToRealMover_type]]

Este mover es útil para construir protocolos específicos o para dejar de ignorar partes de tu Pose. Un residuo virtual es un residuo que no se puntúa ni se escribe en un PDB.


## Caso de uso de ejemplo

Este mover se usó para hacer un muestreo iterativo y semienumerativo de las ramas de carbohidratos en el mover GlycanTreeRelax.
