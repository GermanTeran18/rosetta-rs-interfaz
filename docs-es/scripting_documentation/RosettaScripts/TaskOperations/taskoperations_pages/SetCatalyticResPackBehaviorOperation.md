# SetCatalyticResPackBehavior
*Volver a la página de [[TaskOperations|TaskOperations-RosettaScripts]].*
## SetCatalyticResPackBehavior

[[include:to_SetCatalyticResPackBehavior_type]]

Si la opción -enzdes::ex\_catalytic\_rot \<number\> está activa, el muestreo extra\_sd de cada ángulo chi de los residuos catalíticos se hará según \<number\>; es decir, se pueden sobremuestrear selectivamente los residuos catalíticos.
