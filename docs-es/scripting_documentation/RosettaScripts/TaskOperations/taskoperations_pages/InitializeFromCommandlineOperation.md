## InitializeFromCommandline

Lee las opciones de la línea de comandos. Por ejemplo, -ex1 -ex2 (no lee el resfile a partir de las opciones de línea de comandos). Esta TaskOperation se quejará de un método no implementado, pero puedes ignorar el mensaje sin problema.
