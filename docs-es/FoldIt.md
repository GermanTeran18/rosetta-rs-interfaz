# Foldit

## Foldit
[[Foldit|https://fold.it]] es un juego basado en Rosetta que, en la práctica, reparte el problema del plegamiento de proteínas entre una multitud de participantes. Foldit se apoya en la intuición y la capacidad de resolución de problemas de las personas para encontrar conformaciones de proteínas de baja energía, en lugar del enfoque típico de Rosetta (exploración Monte Carlo del espacio conformacional). Foldit ha tenido éxito en problemas de predicción de estructura y de diseño de proteínas.

Foldit está pensado como una interfaz de propósito general, de fácil acceso, para Rosetta. No todos los protocolos de Rosetta están integrados en Foldit, pero sí ofrece acceso con un solo botón a algoritmos centrales de Rosetta, como el minimizador de energía y el packer de cadenas laterales. Si tienes un problema de investigación que podría beneficiarse del modelado de proteínas por colaboración masiva, [escribe al equipo de Foldit](mailto:mail.fold.it@gmail.com).

## Foldit Standalone

También hay disponible una versión de Foldit sin juego para uso individual. [[Foldit Standalone|https://fold.it/standalone]] está pensado para científicos en un entorno de investigación. El usuario puede cargar y modificar archivos PDB propios usando Rosetta mediante la interfaz gráfica de Foldit. Foldit Standalone no se comunica con los servidores de Foldit ni tiene acceso a los desafíos colaborativos de Foldit.  



Para más información, consulta la [[página principal de Foldit|https://fold.it]].
La publicación original que describe Foldit se puede encontrar [[aquí (enlace a PubMed)|http://www.ncbi.nlm.nih.gov/pubmed/20686574]].
