#Escribir una aplicación de Rosetta

Uno de los principales objetivos de diseño de Rosetta es que escribir nuevas aplicaciones y ampliar protocolos existentes sea fácil. Esta sección pretende mostrar a un desarrollador cómo escribir una nueva aplicación con un nuevo protocolo. Se guiará al lector a lo largo del proceso de

-   escribir un nuevo Mover
-   escribir una nueva aplicación usando el distribuidor de trabajos y el nuevo Mover.
-   usar Doxygen para documentar tu código y escribir una página de tutorial para tu aplicación

Después de leer esta guía, el lector debería poder escribir sus propias aplicaciones de Rosetta.

Esta guía está en construcción.  Claramente hace falta una página de guía de ayuda "Cómo escribir la guía 'Escribir una aplicación de Rosetta'".
